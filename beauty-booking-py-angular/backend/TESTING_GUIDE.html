Exact Commands (PowerShell)

1) Run all backend tests

Set-Location C:\Repos\BeautyBooking\beauty-booking-py-angular\backend
py -m pytest -q

2) Verbose output

Set-Location C:\Repos\BeautyBooking\beauty-booking-py-angular\backend
py -m pytest -vv

3) Run one file

Set-Location C:\Repos\BeautyBooking\beauty-booking-py-angular\backend
py -m pytest tests/test_voice_routes.py -vv

4) Run one test function

Set-Location C:\Repos\BeautyBooking\beauty-booking-py-angular\backend
py -m pytest tests/test_voice_routes.py::test_booking_endpoint_returns_danish_confirmation_for_da_language -vv

5) Stop on first failure

Set-Location C:\Repos\BeautyBooking\beauty-booking-py-angular\backend
py -m pytest -x -vv

6) Debug first failing test in terminal (pdb)

Set-Location C:\Repos\BeautyBooking\beauty-booking-py-angular\backend
py -m pytest --pdb -x -vv

If You Are in C:\Repos\BeautyBooking

Do not run pytest directly from here for backend tests.

Use one of these instead:

Set-Location C:\Repos\BeautyBooking\beauty-booking-py-angular\backend
py -m pytest -q

Or one-line command:

py -m pytest -q C:\Repos\BeautyBooking\beauty-booking-py-angular\backend\tests

VS Code Test Explorer

  1. Open the backend folder as your active workspace root, or make sure tests are discovered under backend/tests.
  2. Select Python interpreter that has pytest installed.
  3. Run or debug tests from the Testing panel.

Common Issues

  • No tests found / failures only from root: wrong working directory. Move to backend directory first.
  • Import or fixture errors: run tests via py -m pytest (not by executing test files directly).
  • Different results between terminal and VS Code: check interpreter mismatch.
